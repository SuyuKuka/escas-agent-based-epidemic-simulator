# Modèle SIR

Le modèle SIR est un modèle compartimental théorisé en 1927 et est le plus simple et connu en épidémiologie.
Il permet de comprendre les tendances de contagion des maladies. Pour autant, ce modèle n'est pas un outil de prédiction.
